Every screen template found in the community Figma file CFLIX Design System 2024 (Website ver.) 🎥 (Community), built in the order the frames appear in that file. Static HTML and CSS. No JavaScript, no framework, no business logic.

What is measured. Colors and type values were read as literal text off the Figma canvas and live in tokens.css.
What is inferred. Component geometry (radii, heights, borders, gaps) is printed nowhere in that file and is read off the artwork.
What is placeholder. Poster art and video stills are baked into the Figma canvas and cannot be extracted anonymously, so every image is a gradient block carrying the real printed title.
Fonts. The file names CFLIX Sans Font and Bebas Neue. Neither is available here, so a system sans stack stands in.
Left for production. The Profile section on UserProfileAvatar was unreadable at every zoom tried, and the About page is a credits frame rather than a screen.
